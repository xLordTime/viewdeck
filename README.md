# Viewdeck
German-language presentation sharing for OpenAI Sites. Requires a public Worker with an R2 binding named BUCKET. The Sites gateway supplies authenticated identity and must strip client-supplied identity headers. Never expose the Worker directly outside this gateway. Create .openai/hosting.json with the Sites project_id and r2 binding, then run node build.mjs (Node 22+, PowerShell 7 on Windows or zip on Linux). Deploy dist/server/index.js with the manifest. ChatGPT login uses the platform sign-in endpoint. Access codes are bearer secrets. Office previews require a publicly reachable file URL and send it to Microsoft's Office viewer after a viewer clicks the preview button. Limits depend on the format and Microsoft's viewer. Original download is always available.
Optional Google and Discord OAuth use GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, DISCORD_CLIENT_ID and DISCORD_CLIENT_SECRET in Sites runtime secrets. Register /auth/google/callback and /auth/discord/callback on the public origin with the corresponding provider.
